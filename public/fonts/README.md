As fontes desta pasta usam os desenhos de Playfair Display, sob a licença
SIL Open Font License incluída em OFL-Playfair.txt.

Os arquivos `playfair-*-variable-*` são os WOFF2 latinos originais do Google
Fonts, com todos os pesos e caracteres. Os arquivos `editorial-*-400-*` são
instâncias do eixo `wght=400`, geradas com FontTools varLib.instancer. Receberam
o nome interno HH Editorial para respeitar o nome reservado da licença.
Nenhum caractere foi removido. Os pesos de 401 a 900 usam os originais.

Os nomes de arquivo incluem SHA-256 do conteúdo para permitir cache imutável.
Ao atualizar uma fonte, atualize também os URLs no layout e no CSS global.
